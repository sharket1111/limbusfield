# Anomaly Field — 이상현상 결투장

브라우저에서 바로 하는 카드 난투 게임입니다. 무기로 공격하고, 방어구로 합을 하고, 정신력을 깎아 E.G.O를 쓰며 마지막 1명이 남을 때까지 싸웁니다.
분위기는 "어두운 도시의 회사와 이상현상에서 뽑아낸 장비"로 잡았고, 카드는 모두 오리지널입니다.

## 실행

설치나 빌드 없이 `index.html`을 브라우저로 열면 됩니다.
(GitHub Pages로 저장소를 공개하면 그대로 웹에서 플레이할 수 있습니다. 멀티 플레이도 GitHub Pages에서 그대로 동작합니다.)

## 🌐 멀티 플레이

- 타이틀의 **멀티 플레이** → **방 만들기** → 나온 5자리 코드를 친구에게 알려 주면, 친구가 코드를 넣고 **참가**합니다 (최대 6명, 빈자리는 CPU로 채울 수 있음).
- **온라인**: 서버 없이 브라우저끼리 직접 연결(WebRTC P2P, PeerJS). 처음 연결할 때만 PeerJS 공용 중계 서버를 거칩니다. 일부 회사·학교 네트워크에서는 막힐 수 있습니다.
- **같은 브라우저의 다른 탭**: 한 컴퓨터에서 탭 여러 개로 하거나 테스트할 때.
- 게임은 **방장 브라우저**에서 진행되고(방장이 모든 행동을 검증), 참가자는 자기 손패만 볼 수 있습니다. 참가자가 나가면 CPU가 이어받습니다.
- 덱 방식: **기본 카드만** / **기본 + 모두의 카드팩** (공용 덱) / **개인 덱** (각자 자기 팩). 「팩 코스트 상한 적용」을 켜면 상한을 넘는 팩으로는 시작할 수 없습니다.

## 💰 코스트

모든 카드는 스펙(위력·코인·효과·특수 능력)으로 **코스트 1~12**가 자동 계산됩니다 (`js/cost.js`).
카드팩의 코스트 합계(코스트 × 장수)가 **150 이하**여야 대전 규격이고, 개인 덱은 **20장 이상**이어야 합니다.
혼자 하기의 개인 덱 모드에서는 CPU도 기본 카드로 같은 코스트(150)의 덱을 무작위로 짜서 나옵니다.

## 규칙 요약

- HP 100 / 정신력 0 / 20원 / 카드 7장으로 시작, 턴마다 1장 드로우 (손패 최대 10장)
- **무기**: 상대를 공격하고 턴 종료. `보조` 무기는 다른 무기에 덧붙여 공격력을 합칩니다.
- **합 (무기 vs 방어구)**: 공격 위력 = 공격력 + 코인 3개(앞면당 +2). 방어구를 내면 방어 위력 = 방어력 합계 + 코인 3개로 합.
  공격이 이기면 차이만큼 피해, 방어가 이기면 완전 방어, 같으면 상쇄. 방어구를 안 내면 공격 위력 그대로 피해.
- **방어구**: 같은 속성 또는 전속성만 낼 수 있습니다. 속성: 물리 / 화염 / 냉기 / 광휘 / 그림자
- **정신력(SP)**: -45 ~ +45. 코인 앞면 확률 = 50% + 정신력%. -45가 되면 **공황**(한 턴 휴식 후 0으로 회복)
- **E.G.O**: 정신력 소모. 공격·강탈·기절은 턴 종료, 회복·정화는 턴 유지
- **도구**: 턴을 끝내지 않음
- **돈(원)과 거래** (갓필드 원작의 매입·매각·환전 규칙 기반): 모든 카드에 가격이 있고(E.G.O는 0원), 최대 99원
  - 🛒 **매입**: 상대 손패에서 무작위 1장 공개 → 살지 선택, 사면 가격을 상대에게 지불 (턴 종료)
  - 💸 **강매**: 내 카드 1장을 상대에게 강제로 판매. 돈이 모자라면 정신력(0까지) → HP 순으로 지불. 판매로 쓰러뜨릴 수도 있음 (턴 종료)
  - 💱 **환전**: HP·정신력·돈을 1:1로 재배분, 합계 유지 (턴 유지)
  - 거래 카드는 막을 수 없음. 「도금된 명패」·「은박 결재판」은 약하지만 비싼 강매용 카드
- **기도**: 카드 1장 + 정신력 10, 턴 종료 (손패가 가득 차 있으면 1장 버리고 뽑음)
- **💢 흐트러짐**: 피격 피해만큼 흐트러짐 게이지(40)가 줄고, 0이 되면 다음 턴을 쉬며 그동안 방어 불가·받는 피해 1.5배. 진동 폭발로도 깎임
- **키워드** (위력/횟수): 🔥화상(턴 시작 피해) · 🩸출혈(공격할 때 피해) · 〰진동(진동 폭발 시 흐트러짐 피해) · 💥파열(피격 시 추가 피해) · 🌊침잠(피격 시 정신력 감소) · 🌬호흡(치명타) · ⚡충전(충전 소모 효과용) + 취약, 기절, 공황
- **코인**: 카드마다 코인 개수와 코인별 위력·효과를 따로 가질 수 있습니다
  - 던지기 전: 충전 소모 / 일방 공격이면 / 합 중이면 / 상대에게 키워드가 있으면 / 내 HP 절반 이하면 / 내 정신력 기준 이상이면 → 위력 증가, **↻ 코인 재사용**
  - 적중 시 · 앞면 적중 시: 키워드 부여, **키워드 폭발**, 진동 폭발, 흐트러짐 피해, 고정 피해, **방어구 파괴**, **돈 빼앗기** 등
- **테마**: 화면 오른쪽 위 🌙/☀️ 버튼으로 다크 / 라이트 모드 전환 (처음엔 기기 설정을 따름)
- **2D 합 연출**: 합을 하면 두 캐릭터가 무대에서 등장 → 코인이 튀어 오르며 위력 상승 → 동시에 돌진해 충돌 → 이긴 쪽이 베고 진 쪽이 밀려납니다. 일방 공격·무효화도 각각 연출이 있고, 멀티 플레이 참가자 화면에서도 똑같이 재생됩니다
- **🌃 뒷골목 배경**: 스모그 낀 빌딩 숲, 네온 간판, 전선과 전구, 가로등이 있는 골목을 코드로 그린 배경. 다크 모드는 밤, 라이트 모드는 안개 낀 해 질 녘. 뒷골목의 밤에는 비가 내립니다
- **📐 가장자리 UI**: 화면 모서리 꺾쇠 프레임, 사선 줄무늬 바, 세로 글귀와 실제 시각, 모서리가 잘린 패널·버튼
- **🎨 캐릭터 꾸미기**: 머리 모양·머리색·눈·눈 색·피부·옷·옷 색·장신구·장신구 색을 골라 내 캐릭터를 만듭니다 (색은 직접 고르기도 가능). 플레이어 패널에는 초상화로 나오고, 멀티에서는 상대에게도 보입니다. CPU는 이름에 따라 정해진 모습으로 나옵니다
- **🌙 뒷골목의 밤**: 100턴(전체 턴 합산)부터, 카드를 뽑을 때 30% 확률로 🧹 청소부(10/20/30 피해) 또는 🛢 연료통(HP 10 / 정신력 10 / 10원 중 하나)이 나옵니다.

수치(체력, 코인 수, 밤 시작 턴, 이벤트 확률 등)는 `js/data.js`의 `RULES`에서 바꿀 수 있습니다.

## 🛠 카드 공방 (웹에서 카드 만들기)

타이틀의 **카드 공방**에서 직접 카드를 만들 수 있습니다.

- 종류(무기 / 방어구 / E.G.O / 도구), 이름, 속성, 사진, 기본 위력, 정신력 소모, 가격, 장수, 등급, 설명
- 카드 효과: 사용 시 / 적중 시 (방어구는 방어 시 / 방어 성공 시)
- **코인별 위력과 효과**: 적중 시, 앞면 적중 시, 충전 소모 → 코인 위력 증가
- 특수 능력: 보조 무기, 전체 공격, 관통, 2회 공격, 흡혈, 반사
- **카드팩**: 카드를 여러 팩으로 나눠 저장하고, 팩마다 코스트 합계·장수·대전 규격 여부가 표시됩니다
- 카드팩은 이 브라우저(localStorage)에 저장되고, **팩 내보내기 / 가져오기(JSON)**로 백업·공유할 수 있습니다
- 타이틀의 「덱 구성」: *기본 카드만* / *기본 + 내 카드팩* / *개인 덱(내 팩 vs 같은 코스트의 CPU 덱)*

## 카드 추가/수정

`js/data.js`의 `CARDS` 배열에 항목을 추가하거나 고치면 바로 반영됩니다. 사용할 수 있는 필드와 특수효과(`fx`) 목록은 파일 맨 위 주석에 정리해 두었습니다.

```js
{ id: 'w_example', type: 'weapon', name: '새 무기', attr: 'fire', atk: 14, count: 2, rarity: 2, fx: ['burn'], flavor: '설명 문구' },
```
